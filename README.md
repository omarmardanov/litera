# Прототип страницы услуги — Литера.Студия

Макет карточки услуги («Подарочный сертификат») и страницы раздела.
Собран под мобильный экран, статические файлы без сборки.

- `index.html` — главная
- `poligrafiya.html` — направление
- `category.html` — страница раздела
- `sertifikat.html`, `advent.html` — карточки услуги
- `case.html` — карточка работы
- `projects.html` — работы
- `blog.html` — блог, `article.html` — статья
- `contacts.html` — контакты
- `_canvas.html` — все типовые страницы одним холстом, как артборды: смотреть на десктопе

Страницы связаны между собой; ссылки на то, чего в прототипе нет,
ведут на живой сайт.

Страницы собираются из `_parts/` и `_pages/` скриптом `build.py`,
собранные файлы руками не правятся. Подробнее — `_parts/README.md`.

Демонстрационный макет. Цены и сроки условные, подлежат уточнению.
