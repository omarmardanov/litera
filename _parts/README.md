# Части страниц

Всё, что повторяется на страницах, лежит здесь по одному файлу на блок,
а страницы собираются из них скриптом `../build.py`.

Правило: **если разметка на двух страницах совпадает — это часть.**
Скопированный блок расходится молча: так раздел отстал от главной на пять
стилей и четыре скрипта, а форма на нём осталась без поля услуги.

В `_pages/` остаётся только своё у страницы: заголовок, описание, адреса,
микроразметка и содержимое блоков.

## Как править

- общий блок — здесь, в `_parts/`;
- своё у страницы — в `_pages/<страница>.html`;
- потом `python3 build.py --bump` из папки `_публикация`.

Собранные страницы лежат рядом с `assets/` — их отдаёт сервер, руками
их не правят: затрутся при следующей сборке. В начале каждого собранного
файла об этом написано.

## Что умеет шаблон

| Директива | Что делает |
|---|---|
| `<!-- @include lead.html -->` | вставить часть |
| `<!-- @set dir poligrafiya -->` | переменная страницы, в частях `{{dir}}` |
| `<!-- @block what -->…<!-- @endblock -->` | содержимое для слота `what` в части |
| `<!-- @slot what -->…<!-- @endslot -->` | место в части; содержимое между — по умолчанию, если страница блок не задала |

Версия `?v=` подставляется в `{{v}}` из `_build.json`, ключ `--bump` её
поднимает разом для всех ассетов. Сборщик падает, если часть не найдена
или осталась неподставленная переменная.

## Части

| Файл | Что это | Шаблон WordPress |
|---|---|---|
| `head.html` | неизменное в `<head>`: кодировка, вьюпорт, og-константы, шрифты | `header.php`, верх |
| `styles.html` | все стили, список один для всех страниц | `wp_enqueue_style` |
| `top.html` | шапка, метка прокрутки, панель меню | `header.php` + `menu.php` |
| `how.html` | «Как мы работаем» — общие шаги без сроков | `template-parts/how.php` |
| `proof.html` | довод перед формой на всех страницах: `figures.html` + `clients.html` | `template-parts/proof.php` |
| `figures.html` | цифры «13 / 820+ / 640+» | `template-parts/figures.php` |
| `clients.html` | лента логотипов клиентов | `template-parts/clients.php` |
| `lead.html` | форма заявки; слот `what` — поле услуги (на главной список) | `template-parts/lead.php` |
| `footer.html` | подвал | `footer.php` |
| `cookie.html` | уведомление о куках | `footer.php` |
| `chat.html` | виджет связи (на живом сайте — Битрикс24) | `footer.php` |
| `dialogs.html` | модальные окна: ролик, памятка | `footer.php` |
| `scripts.html` | все скрипты, список один для всех; каждый сам проверяет, есть ли его блок | `wp_enqueue_script` |

## Что не часть

Разметка общая, содержимое своё у каждой страницы — остаётся в `_pages/`:

- **работы** (`ls-works`): вкладки «Фото · Видео», по три кадра на работу;
  на главной по одной работе на направление, на разделе — на группу услуг,
  на карточке — по продукту;
- **«Ещё из раздела»** (`ls-related`): соседние услуги;
- **вопросы / пары «что выбрать»** (`ls-faq`): один аккордеон, свой текст;
- **шаги на карточках** (`ls-how`): та же разметка, что в `how.html`,
  но со сроками под продукт — это данные карточки, а не шаблон.
